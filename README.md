# Bilibili Downloader

## 项目是什么

一个运行在 Windows 本地的 Bilibili 下载工具，通过浏览器式本地界面使用，体验接近普通桌面软件，不要求用户使用命令行。

## 核心功能

- 单视频解析与下载：输入 B 站视频链接，显示封面、标题和 UP 主；支持最高 1080P 视频 MP4 或仅音频 M4A。
- 多 P 视频：支持单独勾选、批量选择、全选和取消全选。
- UP 主批量下载：输入主页链接获取视频投稿，显示封面、标题、发布时间和时长；支持勾选、全选/取消全选、视频或音频批量下载，以及全部、最近一年、最近半年、最近三个月筛选；使用分页加载。
- 下载任务区：显示任务、进度、速度、状态和简要错误原因；支持取消、失败重试和打开下载目录。
- 设置：首次选择并记住默认下载目录，支持修改；支持 B 站扫码登录、登录状态查看、导出诊断日志和打开日志目录；敏感登录信息必须脱敏。

## 使用方式

Windows 下通过类似普通软件的入口启动，后台静默运行本地服务并自动打开浏览器页面；启动时不显示命令提示符窗口。

## 当前阶段

先建立基础框架，逐步跑通单视频下载、UP 主视频选择、批量下载、任务状态和基础设置的核心流程。

UI 第一阶段以清晰、统一、现代、易用为目标，不做过度视觉设计，也不使用粗糙或花哨的图标。

## 关键约束

- Windows 优先，视频最高先支持 1080P，默认视频格式为 MP4、音频格式为 M4A。
- 暂不支持专栏、字幕、弹幕、4K 等扩展功能。
- 优先复用成熟开源下载能力，不自行重写 B 站解析核心；后续优先评估 BBDownNext 等现有方案。
- 不擅自扩展需求。

## 运行说明

1. 电脑需要安装 Python 3.12 或更高版本。
2. 正常使用时只需双击 `启动工具.vbs`；工具会静默准备 BBDownNext、FFmpeg，确认本地服务可用后自动打开页面。
3. 启动失败会显示中文提示，详细原因保存在 `%APPDATA%\BilibiliDownloader\logs\launcher.log`。

首次使用时选择默认下载目录。配置与诊断日志仅保存于当前 Windows 用户目录，不会提交到 Git。
