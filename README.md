# CourseFlow

## 项目定位

CourseFlow 是 Windows 本地课程媒体获取与 AI 转写工具，通过本机网页界面管理 B 站媒体下载、转写任务和文字稿。腾讯会议当前采用浏览器桥接插件解析单个回放；本阶段只显示标题、时长和媒体是否找到，不下载媒体。

## 当前功能

- B 站公开视频解析，支持多 P 选择、UP 主投稿分页、合集/系列浏览。
- 下载视频 MP4 或仅音频 M4A；下载任务支持进度查看、取消和失败重试。
- 将 B 站媒体送入转写中心，或手动添加本地音频；任务支持排队、取消、历史查看、复制全文及导出 TXT。
- 转写引擎可选本地 FunASR 或小米 MiMo-V2.6-Flash；MiMo 凭据加密保存在当前 Windows 用户目录。
- 设置中管理下载目录、B 站扫码登录和诊断日志。
- 腾讯会议通过 Chrome/Edge 的 CourseFlow Meeting Bridge 扩展，在用户当前浏览器登录态中后台解析单个回放；CourseFlow 管理任务，扩展只负责识别标题、时长和唯一 MP4 请求上下文。

## 启动

Windows 下双击 `启动工具.vbs`。程序会静默准备 BBDownNext、FFmpeg，并打开本地界面；首次使用时选择默认下载目录。需要 Python 3.12 或更高版本。

配置和诊断日志保存在当前 Windows 用户的 AppData，不会提交到 Git。

## 腾讯会议浏览器桥接

浏览器负责腾讯会议登录，CourseFlow 负责创建/显示解析任务，扩展负责在同一浏览器中后台打开回放并捕获 MP4 请求上下文。扩展不保存 Cookie、Authorization、签名媒体 URL 或原始请求头；CourseFlow 只在当前进程内暂存敏感媒体上下文，30 分钟后过期，不写配置、日志或页面响应。Playwright 独立登录路线已停用并保留旧代码，等待后续清理。

开发态可在 Chrome/Edge 扩展管理页启用“开发者模式”并加载仓库的 `browser-extension` 目录。先在浏览器正常登录腾讯会议，再在 CourseFlow 腾讯会议页解析单个有权限的回放。当前阶段不下载媒体、不提取音频、不转写、不做批量文档导入；回放下载功能后续由 CourseFlow 接管。

## 约束

- 优先复用成熟下载能力，不重写 B 站解析核心。
- 不读取浏览器 Cookie；B 站账号通过工具设置中的官方扫码流程登录。
- 视频默认最高支持 1080P；暂不支持专栏、弹幕、4K 等扩展内容。
