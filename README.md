# CourseFlow

## 项目定位

CourseFlow 是 Windows 本地课程媒体获取与 AI 转写工具，通过本机网页界面管理 B 站媒体下载、转写任务和文字稿。腾讯会议页面目前是 UI 占位，尚未接入登录、回放解析或下载。

## 当前功能

- B 站公开视频解析，支持多 P 选择、UP 主投稿分页、合集/系列浏览。
- 下载视频 MP4 或仅音频 M4A；下载任务支持进度查看、取消和失败重试。
- 将 B 站媒体送入转写中心，或手动添加本地音频；任务支持排队、取消、历史查看、复制全文及导出 TXT。
- 转写引擎可选本地 FunASR 或小米 MiMo-V2.6-Flash；MiMo 凭据加密保存在当前 Windows 用户目录。
- 设置中管理下载目录、B 站扫码登录和诊断日志。

## 启动

Windows 下双击 `启动工具.vbs`。程序会静默准备 BBDownNext、FFmpeg，并打开本地界面；首次使用时选择默认下载目录。需要 Python 3.12 或更高版本。

配置和诊断日志保存在当前 Windows 用户的 AppData，不会提交到 Git。

## 腾讯会议后续方向

当前仅提供腾讯会议功能布局，不执行登录、解析或下载。后续计划使用 CourseFlow 管理的独立浏览器 Profile：首次登录或登录失效时打开腾讯会议官方网页供用户微信扫码，登录成功后关闭窗口；正常解析在后台运行且不抢焦点，遇到验证码、重新认证或人工确认时再打开官方页面。本地批量导入计划支持从 TXT、Word 或 Excel 识别回放链接。

## 约束

- 优先复用成熟下载能力，不重写 B 站解析核心。
- 不读取浏览器 Cookie；B 站账号通过工具设置中的官方扫码流程登录。
- 视频默认最高支持 1080P；暂不支持专栏、弹幕、4K 等扩展内容。
